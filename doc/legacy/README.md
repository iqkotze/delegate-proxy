# Legacy-Dokumentation

Die Dateien in diesem Verzeichnis beschreiben den Stand von DeleGate 9.9. Sie nennen Plattformen, Programme, Parameter und Installationswege, die es in der modernisierten Fassung nicht mehr gibt. Die aktuelle Referenz ist [../reference/parameters.md](../reference/parameters.md). Unterschiede zum Original beschreibt [../migration.md](../migration.md).

| Datei | Inhalt |
|---|---|
| `Manual-9.9.md` | Referenzhandbuch 9.9 als Markdown |
| `Manual.htm` | Referenzhandbuch 9.9 als HTML |
| `HowToDG.html` | Anwendungsbeispiele |
| `tutor-en.htm`, `tutor-jp.htm` | kurze Anleitung für Einsteiger, englisch und japanisch |
| `jpconv.htm` | Zeichencode- und MIME-Konvertierung für Japanisch |
| `DG9note.html` | Neuerungen in 9.X |
| `RELEASE-NOTES-9.9.txt` | Release-Notes von 9.0 bis 9.9.13 |

Die Historie des Originals steht außerdem in `delegate/CHANGES`.
